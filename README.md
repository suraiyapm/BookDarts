## Introduction {#intro}

BookDarts is (going to be) a web app for simplifying bookmark organization, with the intention of making the process of digital decluttering as easy as possible.

Personally, I often struggle with keeping my bookmarks organized. I love having things in many categories, but this can often grow into a sort of bookmark-bloat. I end up making far too many categories and sub-categories, and often only revisit a small number.
Additionally, I like to have some separated workspaces of sorts, but as they often frequently change, they grow to be too messy.

Enter BookDarts.

I wanted a way that would make it easier for my brain to handle organizing my bookmarks, and potentially make it a less daunting task to do in large amounts (like completing it piece by piece).

## Concept Features {#features}

> Here, I will go over some (potential) features, and maybe goal features, this web app may have.

  - Basic functionality:
    - Import bookmarks.html file
    - Export bookmarks.html file
    - Move bookmarks
    - Delete bookmarks
    - Create bookmarks
    - Edit Existing Bookmarks (rename/etc)
<br>
  - Visual Concepts:
    - Simple Mode: Swipe left/right to keep/delete
      - Optional: Enable extra bin for ones to sort after.
    - Sort Mode: Swipe from sub-folders into eachother or to parent
      - Optional: Extra bin for sorting afterwards/elsewhere
    - Primarily dragging/swiping/tap option
<br>
  - Misc. Ideas:
    - Possibly: Identifying parent sites with many repeat sub-links?
      - With option to remove, reorder, keep, etc.
        - May help with bookmark bloat!
